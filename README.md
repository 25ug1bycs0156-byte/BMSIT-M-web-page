# BMS Institute of Technology and Management

A standalone, responsive college website for BMS Institute of Technology and Management.

## View locally

Open `index.html` in a browser. The page is self-contained; the typefaces and campus photographs are loaded from external services.

## Publish with GitHub Pages

1. In the repository settings, open **Pages**.
2. Select **Deploy from a branch**, choose `main` and the `/ (root)` folder, then save.
3. Wait for the deployment to complete and open the Pages URL shown in settings.

The website is an informational front-end. Verify institutional details and replace illustrative content or images with approved material before publishing.
